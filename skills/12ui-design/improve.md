# Improve an existing interface

## What to keep

`--retain` defaults to keeping the brand and words (`assets,content`); add `layout` only when geometry must hold.

No combination licenses inventing a product fact. Preserve real claims, numbers, offers, data, and controls. Do not describe sparse real content as a defect to fill with inventions.

Use `--direction` for concrete hierarchy, typography, surfaces, color, controls, and mood.

## Kits

`--redraw` draws new candidates when none fit; `--fresh` buys another conversion of the same winner. Neither is a resume: after a stall, run the free command the kit prints.

Site scope is always a kit that carries an accepted root design across the site's pages; `--apply` takes page scope with a PNG, JPEG or WebP target only.

    12ui improve <url> --scope site --direction "<specific visual direction>" --out-dir <kit>

Apply the kit's `site-plan/APPLY.md` and run the recheck it ends with; inspect every target and any page whose mapping is blocked.
